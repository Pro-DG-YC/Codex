# Encuesta de hábitos digitales

Este repositorio contiene un formulario web en un solo archivo (`encuesta.html`).

## Vista previa local

1. Inicia un servidor estático: `python -m http.server 8000`.
2. Abre `http://localhost:8000/encuesta.html` en tu navegador.

El formulario es responsivo y puedes revisarlo tanto en escritorio como en móvil utilizando las herramientas de desarrollo del navegador.
