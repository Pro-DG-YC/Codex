# Codex

Este repositorio contiene el diseño de una página de marketing para DM Odanić optimizada para Sitejet Builder.

## Previsualización local

1. Instala o usa una versión reciente de Python 3.
2. En la raíz del proyecto ejecuta `python -m http.server 8000`.
3. Abre `http://localhost:8000/index.html` en tu navegador para ver el sitio.

## Estructura

- `index.html`: Estructura HTML principal del sitio.
- `styles.css`: Hojas de estilos con tipografía, grillas y reglas responsivas.
- `assets/`: Mantén aquí las imágenes existentes utilizadas en el diseño.

## Notas

- Todo el contenido permanece en español.
- Las imágenes originales deben conservarse para respetar la identidad visual de la marca.
